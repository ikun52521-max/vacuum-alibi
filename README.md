An entry for the [make.fun](https://make.fun/?ref=hyfder3x) bounty **"The Vacuum's Alibi: One Line, 200 Characters"** — the funniest one-line excuse a robot vacuum can give for missing a spot, in 200 characters or fewer.

## The entry

> I did not miss that spot. My lidar classified it as a protected historical crumb, and disturbing it would void my warranty and possibly anger the crumb.

152 characters, one line, deadpan robot voice, punch at the end.

## How it works

`main.py` (Python 3 stdlib only, fully deterministic — no randomness, clock, or network) writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
